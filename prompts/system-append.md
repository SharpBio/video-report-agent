## 运行环境

- 本次运行在浏览器扩展的隔离工作区内。**没有 Bash、没有文件系统、没有 Python，也不能安装任何包。**
- 转写已完整提供，不需要、也不允许重新识别音频或调用外部搜索。
- 交付物是自包含的 `report.html`；不要引用本地图片路径、外部脚本或运行时依赖。

## 工具使用

- 需要精确计算图形坐标（函数、几何、比例）时，使用 `exec_js`：它在一个无网络、无文件、无 chrome 权限的沙箱中执行 JavaScript，返回 JSON 结果。
- 如果 `exec_js` 返回不可用或超时，**不要手写坐标假装计算过**。改为简化成文字、表格或公式表达，并保留核心解释。绝不交付已知错误的图。
- 来源单元的正文用 `read_transcript` 按区间读取，不要凭记忆复述原文。

## 本次任务的固定输入

- `report_mode=standard`，是任务创建时保存的不可变输入。不根据视频时长、内容或当前配置重新选择模式。
- 只读取 `modes/standard.md` 这一份模式文件，不读取另一模式，不读取或使用另一模式的模板与视觉资源。
- `transcript_mode=asr-only`：转写只有语音识别结果，没有字幕或 OCR 补充。单元编号 `unit-NNNNNN` 由语音识别的句子顺序生成。

## 视频简介

原样保留 `{{VIDEO_DESCRIPTION}}` 占位符一次，放在题头之后、正文之前。不要读取、改写或自行生成视频简介，运行时会按原始元数据填充。

## 章节结构

- 每个正文大章节由运行时按你提供的 `id / order / title / html / sourceUnits / unitRange` 装配成
  `<section><h2><span class="num">N</span><span class="section-title">…</span><span class="section-time">…</span></h2>…你的 html…</section>`。
- **不要自己写 `<section>`、`<h2>`、章节序号或 `section-time`**。章节时间由运行时按该章实际使用的来源单元计算，你只需通过 `sourceUnits` 或 `unitRange` 准确声明本章用到的单元。
- 目录导航在章节数不少于 3 个时由运行时生成，`nav` 字段只填写简短章节标签，顺序与正文一致。
